🔑 Sambung ke GitHub

Halaman ini menyimpan FAQ terus ke repo anda. Untuk itu, ia perlukan token GitHub (sekali sahaja). Token hanya disimpan dalam browser ini.

  1. Buka GitHub → Fine-grained token baru
  2. Token name: TanyaJer, dan pilih Expiration (contohnya 1 tahun)
  3. Repository access: Only select repositories, kemudian pilih repo ini
  4. Permissions: tambah Contents = Read and write, dan Actions = Read-only
  5. Klik Generate token, salin token, dan tampal di bawah
